📝 Repayment & Return Tracking

A simple private record to reduce disagreement and help both sides remember what was agreed.

What this service entails

Record what was given

For money, record the principal amount. For an item, record the item and its basic condition.

Record the date

The hand-off date is written down so both sides have the same starting point.

Record the due date

If repayment or return is expected, the agreed date or instalment plan is stored privately.

Private reminder

A future version can remind both parties before the due date without publishing the debt.

Extension by agreement

If more time is genuinely needed, both sides can privately agree to an extension and record the new date.

Completion confirmation

When repayment or return is complete, both sides confirm it so the record can be closed.

Important safeguards

No automatic penalties. The system should not add interest-like late charges.
No public debtor score. Debt status should not be displayed as public humiliation.
