## App title
PDF Page Equalizer

## Short description
Equalize PDF pages to the same size, margins, and visible layout.

## Full description
PDF Page Equalizer helps correct uneven PDF pages for cleaner viewing and better printing.

Use it when:
- some pages look smaller or shorter than others
- margins are uneven
- two A5 pages are placed on one A4 landscape sheet
- you want a neat, consistent final PDF

### Main features
- Select a PDF from your phone
- Equalize pages automatically
- Make every output page the same final size
- Normalize visible page height and width
- Apply equal margins
- Split A4 landscape spreads into individual A5 pages when needed
- Prepare exact A5 output at 148 × 210 mm
- Save the corrected PDF

### Useful for
- school books
- worksheets
- scanned books
- image-based PDFs
- print preparation
- booklet preparation

### Privacy-focused design
PDF processing is designed to happen locally on the user's device rather than sending the selected PDF to a remote processing server.

### Important note
For strong visual correction, the app may rebuild pages from rendered page images so that visible page content becomes uniform. Users should keep the original PDF as the master copy.
