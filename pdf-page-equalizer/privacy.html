Privacy Policy for PDF Page Equalizer

Last updated: 17 September 2026

Publisher: Islamic Curriculum Trust Foundation
Contact: suyuuutiiii@gmail.com

PDF Page Equalizer helps users resize and equalize PDF pages for cleaner viewing and printing, including A5 output.

1. PDF processing

The app is designed so that PDF page processing happens locally on the user's device. A PDF selected for equalization is handled in the browser or app on the user's phone, tablet, or computer and is not intentionally uploaded by the Equalizer to a remote server for processing.

2. Files selected by the user

The app works only with files that the user intentionally selects. It does not intentionally scan or collect unrelated documents from the user's device.

3. Output files

Corrected PDF output is generated for the user to save or download on the user's own device.

4. Personal information

The core equalizing function does not require the user to provide a name, postal address, phone number, or payment information.

5. Hosting and technical services

The web version may load technical software libraries from third-party content-delivery services. As with ordinary web browsing, those hosting or library providers may receive standard connection information such as IP address, browser type, and request time. The app publisher does not intentionally send the contents of the user's selected PDF to those services for equalization.

6. Device permissions

A downloadable mobile version may request access needed to let the user choose a PDF and save the corrected result. Permissions will be limited to functions needed for the app to work.

7. Children's privacy

The app is a general document utility and is not designed to collect personal information from children.

8. Changes to this policy

This policy may be updated when the app, its hosting, or its features change. The latest version will be published on this page.

9. Contact

For privacy questions, contact Islamic Curriculum Trust Foundation at suyuuutiiii@gmail.com.
