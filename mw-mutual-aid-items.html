🧰 Borrow / Lend Useful Items

Temporary use of a useful item with a clear owner, purpose, condition and return arrangement.

What this service entails

Describe the item

Record what is being lent, such as a tool, textbook, wheelchair, appliance or other useful item.

Record its condition

Both sides note the basic condition before hand-off so normal wear is not later confused with damage.

Agree the use

The borrower states the intended use and agrees not to pass the item to another person without permission.

Set a return date

A realistic return date or borrowing period is agreed before hand-off.

Safe collection and return

A mosque, public meeting point or another verified arrangement can be used instead of exposing private addresses.

Confirm return

Both sides can confirm that the item was returned and the arrangement is complete.

Important safeguards

Borrowed is not gifted. Ownership remains with the lender unless both sides later agree otherwise.
Regulated or dangerous items. High-risk, illegal or regulated items should not be handled through this service.
