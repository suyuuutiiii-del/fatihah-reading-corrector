🧰 Borrow / Lend Useful Items

Temporary use of a useful item with a clear owner, purpose, condition and return arrangement.

What this service entails

Describe the item

The owner records what is being lent, such as a tool, textbook, wheelchair, appliance or other useful item.

Record its condition

Both sides note the basic condition before hand-off so normal wear is not later confused with damage.

Agree the use

The borrower states the intended practical use and agrees not to pass the item to another person without permission.

Set a return date

A realistic return date or borrowing period is agreed in advance, with room for a private extension if both sides consent.

Safe collection and return

The hand-off can use a mosque, public meeting point or another verified arrangement instead of exposing private addresses unnecessarily.

Confirm return

When the item is returned, both sides can record that the borrowing arrangement is complete.

Useful examples

Tools for a small repair
Textbooks or study materials
Wheelchair or mobility aid
Cooking or event equipment
Baby or household equipment
Other lawful, safe and non-regulated items
