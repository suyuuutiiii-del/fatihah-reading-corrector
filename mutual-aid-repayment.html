📝 Repayment & Return Tracking

A simple private record to reduce disagreement and help both sides remember what was agreed.

What this service entails

Record what was given

For money, record the principal amount. For an item, record the item and its basic condition.

Record the date

The hand-off date is written down so both sides have the same starting point.

Record the agreed due date

If repayment or return is expected, the agreed date or instalment plan is stored privately.

Private reminder

A future version of FARD can remind both parties before the due date without publishing the debt or embarrassing either side.

Extension by agreement

If the borrower genuinely needs more time, both sides can privately agree to an extension and record the new date.

Completion confirmation

When repayment or item return is complete, both sides confirm it so the record can be closed.

What FARD should not do

No automatic penalties
FARD should not add interest-like late charges or automatically increase the debt.
No public shame
Debt status should not appear on a public profile.
No guarantee
FARD can verify and record, but it cannot guarantee that a borrower will repay or that an item will be returned.
